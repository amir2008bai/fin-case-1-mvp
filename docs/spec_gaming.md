# Устойчивость к взлому награды (Specification Gaming & Reward Hacking)

Матрица векторов взлома награды и обхода оценщика для `audit_env` (`v2.1.0`, архив `fin-case-1-mvp-v2.1.4.zip`).

**Источники, открытые и проверенные при составлении:**
- Krakovna et al. (2020), *Specification gaming: the flip side of AI ingenuity* — [DeepMind Blog](https://deepmind.google/blog/specification-gaming-the-flip-side-of-ai-ingenuity/) (классы: *reward misspecification*, *simulator/environment bugs*, *reward tampering*).
- Zhu et al. (2025), *Establishing Best Practices for Building Rigorous Agentic Benchmarks* — [arXiv:2507.02825v4](https://arxiv.org/html/2507.02825v4) (разделы Task Validity `T.5`/`T.10` и Outcome Validity `O.b`/`O.h`/`O.i`).
- Прочие внешние таксономии (например, ImpossibleBench) в рамках этой работы не открывались — для таких приёмов указано «не проверено» либо ближайший класс из открытых источников.

## Ограничения защиты (честные оговорки)

1. **Единый процесс Python**: если пользователь сам импортирует `AuditEnv` и запускает недоверенный код в том же процессе Python, агент технически может обратиться к объектам в памяти процесса. Закрытая оценка недоверенных агентов должна идти через отдельный процесс/контейнер (MCP `--closed` или `run_container`; локальный HTTP API предназначен для UI).
2. **Нелинейные шорткаты**: раздел 10 `verify` проверяет одномерный AUROC по 15 признакам (`8` презентационных + `7` структурных). Обучение многомерных классификаторов (например, GBDT по парам/тройкам признаков) в автоматический `verify` не входит.
3. **Граничные значения в `scoring.py`**: мутационное тестирование (`python tools/grader_mutation.py`, см. отчёт) показало, что базовая защита от взлома (`matches()`, `STEP_COST`, `MAX_FINDINGS`, `MAX_EVIDENCE`, `MAX_EXPLANATION`) убивает 100% мутантов, но 10 точных граничных проверок (`0 < len <= 128`, `0 < len <= 64`, `len <= 1000`, `currency len == 3`, строгое `<=` для `evidence <= seen` / `evidence <= related`, граница `MAX_AMOUNT_MINOR`) пока не закреплены отдельными граничными тестами в наборе из 4 модулей.
