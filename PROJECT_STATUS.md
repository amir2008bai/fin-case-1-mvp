### 2026-11-22 (аудит адаптеров: изоляция и интерактивные часы)

- Процесс агента больше не наследует `AUDIT_ENV_SECRET` и `AUDIT_ENV_KEY_FILE` (`runner.agent_environment`): раньше агент в подпроцессе читал ключ оценщика из окружения и мог пересчитать эталон закрытого эпизода. Файл ключа в домашней папке от процесса того же пользователя это не закрывает — граница изоляции по-прежнему контейнер агента.
- 60-секундный дедлайн оцениваемого прогона обрывал сессии UI и MCP, где действует человек или LLM. Теперь `AuditEnv(interactive=True)` поднимает потолок только для адаптеров: сессия API — 1 час, MCP — 30 минут с момента `initialize` (`mcp --timeout`). `AuditEnv()` и `runner` без изменений: 60 с.
- `mcp --compact` больше не пересказывает политику: прежний «компактный» текст терял правила `policy.findings` (что класть в `affected_ids`, сумму и доказательства), `collections`, возвраты и остатки, то есть часть типов в этом режиме была нерешаема. Политика отдаётся дословно, сжимаются только страницы таблиц (без потерь).
- API для UI: проверка `Host` (DNS rebinding), `POST` только с `Content-Type: application/json` и без чужого `Origin` (403/415).
- Документация приведена к измеренному: `micro` описан как логистический ранжировщик поверх кандидатов и признаков-индикаторов правил `checks.py` (с весами без обучения результат тот же), а не как самостоятельно обученный аудитор; таблицы README и `failure_analysis.md` перегенерированы; из текста убраны название реальной компании и агрегаты её документов (кейс: реальные финансовые данные блокируют оценивание); ограничение «обязательные ошибки только в актах услуг» записано честно.
- `benchmark` получил `--repeats` и ключ, выводимый из `--seed`: таблицы README теперь воспроизводятся командой. Контроль утечек в `verify` идёт на 360 эпизодах с порогом 0.06 вместо 36 эпизодов с порогом 0.15, при котором найденная им же утечка (дрейф 0.10) прошла бы. Теперь у целей есть окно периода, шаг отражается от границы тем же случайным числом, поэтому остальные эпизоды не изменились. Самая маленькая конфигурация без «двойников» давала 19 документов и падала на `reset` — добавлен добор до 20. Проверено: 0 сдвинутых целей на 52 000 миров, `selfcheck --n 1500` без сбоев, `tests/test_generator_regressions.py`.
