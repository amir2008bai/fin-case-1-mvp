# Состояние проекта

**Стадия:** ядро MVP готово к сдаче: 6 типов ошибок, взаимодействия, оценщик, уровни сложности, обученная микромодель, red team, экономия шагов, API для UI и документация. PR #3 влит в `main`. Тег `v1.0.0` указывает на предыдущий снимок.

**Контекст:** хакатон, финансовый кейс № 1 (RL-среда для ИИ-аудитора). Сдача 22.11.2026 23:59 (Астана).

**Состояние MVP:** `python -m audit_env verify` охватывает 101 тест, 22 проверки контракта, изоляции и награды, независимую проверку эталона, сверку `data/`, закрытые эпизоды, устойчивость оценщика, экономию шагов и проверку признаков оформления. UI и презентацию делают другие участники команды. LLM-обвязка v1 сохранена вне `verify`.
