# Состояние проекта

**Стадия:** работающее ядро и тракты обучения.

**Контекст:** хакатон, финансовый кейс № 1.

**Состояние MVP:** два типа ошибок, воспроизводимая среда, микромодель и монитор. RAG доступен как инструмент LLM. Подготовлены генератор обучающих данных, LoRA SFT и обновление по награде среды. Сценарии FX, отсечение периода и их сочетания остаются следующей задачей.

## История

### 2026-11-19

- Перенесено ядро среды и добавлены RAG по открытым записям, экспорт SFT, предпочтений и наград, LoRA SFT, RL и закрытая оценка. Рецепт для команды в [docs/llm-training.md](docs/llm-training.md).
- Проверены 24 теста, контейнеры без сети, экспорт 96/24 эпизодов и обновления SFT/RL на тестовой CPU-модели. Качество на большой модели пока не измерялось.

- Создан приватный репозиторий для команды. Добавлены README, правила для агентов и журнал состояния.
